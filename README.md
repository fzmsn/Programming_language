# Programming_language
Programming study materials, including the official Java Language Specification (JLS) PDF and foundational notes.

## 📚 Repository Contents
1. JLS27 (Java SE 27 Official Language Specification PDF) – The authoritative document from Oracle, defining the complete syntax rules for Java.
> ⚠️ Note: This document is highly theoretical and dense; it is not suitable for absolute beginners. It is best used for looking up specific syntax details or troubleshooting compilation errors.

2. Java study notes and code examples, designed to be used alongside the "Runoob" (菜鸟教程) Java tutorial.
